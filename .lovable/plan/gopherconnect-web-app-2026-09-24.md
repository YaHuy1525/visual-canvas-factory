# GopherConnect Web App

## Build
- Create a responsive application shell with a dark navy top bar, collapsible sidebar, active navigation, and Huy’s account label.
- Add four real pages: Dashboard, AI Insights, Research Gateway, and Admin.
- Apply the supplied navy, blue, light-blue, and white visual system with clean typography, restrained shadows, and no icons.

## Page behavior
- Dashboard: summary metrics, connected product cards, and recent insight cards.
- AI Insights: working severity filters and actions for each insight.
- Research Gateway: species and query-type form, example results, tables, and downloadable CSV export.
- Admin: product, API key, and audit-event tables with responsive layouts.

## Technical details
- Use TanStack Router routes for every sidebar destination and unique page metadata for each.
- Keep mock data in the interface only; no login, database, or external API is required.
- Define all visual colors and typography as reusable semantic tokens in the global design system.
- Verify navigation and interactive controls at desktop and mobile sizes.
